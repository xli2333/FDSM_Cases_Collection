# 复旦大学管理学院案例库 (FDSM Cases Collection)

一个使用 Next.js 14 构建的现代化、交互式案例库展示平台，旨在展示复旦大学管理学院在管理案例教学与研究方面的创新成果，特别是针对科创企业管理情境的深度探索。网站融合了动态视觉特效与丰富的内容展示，传递"无科创、无未来"的核心理念。

## ✨ 核心特性

- **科创主题视觉** - 采用黑金/蓝橙配色，结合动态渐变与粒子效果，凸显科创与未来的主题
- **交互式服务体系** - 通过动态卡片网格展示"经典案例"、"短案例"、"多媒体案例"等核心服务
- **动态关键词墙** - Canvas 2D 粒子系统呈现"人工智能"、"新能源"等管理热点词汇
- **合作伙伴扫描** - 激光扫描特效生动展示哈佛、毅伟等国际顶级案例库合作伙伴
- **发展历程时间轴** - 垂直交互式时间轴，记录案例库建设的重要里程碑
- **荣誉成果展示** - 玻璃拟态卡片展示"全国百篇优秀管理案例"等代表性荣誉
- **响应式设计** - 完美适配桌面、平板及移动端设备，提供流畅的浏览体验
- **流畅动画交互** - 基于 Framer Motion 的入场动画、微交互及平滑滚动效果

## 🛠️ 技术栈

### 核心框架
- **Next.js 14.2.16** - React 框架，使用 App Router 架构
- **React 18** - 用于构建用户界面的 JavaScript 库
- **TypeScript 5** - 提供静态类型检查，确保代码健壮性

### 样式与 UI
- **Tailwind CSS 4.1.9** - 原子化 CSS 框架，构建自适应界面
- **Radix UI** - 无头组件库，提供无障碍交互原语
- **Framer Motion** - 强大的 React 动画库
- **Lucide React** - 现代化图标库
- **class-variance-authority** - 用于管理组件样式的变体

### 3D 与视觉效果
- **Three.js (0.180.0)** - WebGL 3D 图形库
- **@react-three/fiber** - Three.js 的 React 渲染器
- **@react-three/drei** - 3D 场景辅助工具集
- **@tsparticles** - 高性能粒子动画引擎
- **Canvas API** - 用于构建自定义的高性能 2D 图形特效

### 附加库
- **react-hook-form** - 高效的表单状态管理
- **zod** - TypeScript 优先的模式声明和验证库
- **embla-carousel-react** - 轻量级轮播组件
- **sonner** - 优雅的 Toast 通知组件

## 🎨 设计亮点

### 沉浸式首屏体验
- **动态渐变标语** - "无科创 无未来"采用流光渐变效果，视觉冲击力强
- **聚光灯特效** - 顶部聚光灯增强页面的空间感和层次感
- **粒子关键词墙** - 动态生成的关键词云，直观传达案例库关注的前沿领域

### 交互卡片系统
- **智能网格布局** - 自定义 CSS Grid 实现服务卡片的错落排布
- **弹性展开动画** - 点击卡片平滑展开更多详情，带弹簧物理效果
- **多媒体融合** - 卡片内无缝集成视频播放功能

### 合作伙伴扫描墙
- **激光扫描动画** - 模拟激光扫描效果，动态点亮合作伙伴 Logo
- **实时追踪裁剪** - 基于 Canvas 的实时图像遮罩与裁剪技术
- **高科技感呈现** - 强化平台与国际顶尖机构接轨的形象

### 发展历程交互
- **滚动触发动画** - 时间节点随页面滚动渐次显现
- **左右交替布局** - 优化的视觉动线，提升阅读体验
- **微交互反馈** - 鼠标悬停时的缩放与高亮反馈

## 🚀 快速开始

### 前置要求
- Node.js 18+
- npm 或 pnpm

### 安装与运行

```bash
# 安装项目依赖
npm install

# 启动开发服务器
npm run dev
# 访问 http://localhost:3000

# 构建生产版本
npm run build

# 启动生产服务
npm start
```

## 📱 响应式适配

- **移动端 (< 768px)**: 优化布局堆叠，简化复杂特效，保证加载速度
- **平板端 (768px - 1024px)**: 调整网格列数，适配触控交互
- **桌面端 (> 1024px)**: 完整呈现所有高级特效与宽屏布局
